# BentoTerm releases

Signed, notarized downloads of **BentoTerm**: a macOS terminal for agent fleets, where every agent gets its own window.

- **Requirements:** macOS on Apple Silicon.
- **Install:** open the `.dmg` and drag BentoTerm to Applications.
- **Verify:** builds are signed with Developer ID (team `5J5378K37H`) and notarized by Apple. Each release lists the SHA-256 of its `.dmg`.

The source code is not in this repository.
